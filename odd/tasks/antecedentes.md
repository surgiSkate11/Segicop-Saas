# Antecedentes penales (Ministerio del Interior)

Rework of `apps/antecedentes` aligned with `doc/Requerimientos.docx` ("Validación de antecedentes penales y judiciales"). Automated end to end except the human CAPTCHA step; manual upload always available; never evade anti-bot controls.
Branch: `feat/antecedentes` (stacked on `feat/cuentas-acceso-portal`). Baseline of the user's previous partial work: commit 573d61a. Read until `## Log` before working.

## Specs

- S1 — Scope now: only "Ministerio del Interior" criminal-record certificate. "solo hagamos ese por ahora lo de judicial agregalo como tarea para futuro" (L2). Función Judicial is T9 (future, not now).
- S2 — Automation with failure handling (L2): "debemos hacer una automatizacion para q el proces sea inmediato y q responda correctamente ante fallas por ejemplo poniendo limitaciones de intentos e indicando q vuelv a intentarlo luego de cierto tiempo y  q siempre permitar la opcion de hacerlo manualmente". Requirements: "Tiempo agotado o 5xx: Máximo dos reintentos con espera incremental; después, revisión." "4xx o acceso denegado: No reintentar automáticamente; registrar evidencia técnica minimizada." "Carga manual controlada … Debe estar siempre disponible como contingencia." User-facing message tells when to retry.
- S3 — No evasion (requirements): "El flujo debe detenerse en estado CAPTCHA_REQUERIDO y permitir intervención humana autorizada." "No se implementará evasión, inyección oculta de tokens ni resolución por terceros sin autorización escrita del titular del portal". ANT-004 "Detenerse ante CAPTCHA, términos, bloqueo, persona no encontrada o respuesta inesperada." Observed: the Ministerio portal is behind Imperva Incapsula (cookie challenge); the Función Judicial SPA uses reCAPTCHA (`siteKeyCaptcha`, `numeroConsultasCapcha:1`).
- S4 — Assisted query (L2 Q4 "Pestaña en su navegador"): SIGECOP opens the official portal in a new tab of the operator with the cédula ready to copy; the operator solves the CAPTCHA, downloads the PDF and drags it into SIGECOP.
- S5 — States (requirements diagram): CREADA, AUTORIZACION_PENDIENTE, LISTA, EN_CONSULTA, CAPTCHA_REQUERIDO, RESULTADO_OBTENIDO, PDF_RECIBIDO, DATOS_COINCIDENTES, AUTENTICIDAD_PENDIENTE, VALIDADA, REQUIERE_REVISION, FALLIDA, VENCIDA, CANCELADA, with the transitions of the diagram. "FALLIDA: No se obtuvo un resultado válido; no equivale a ausencia de antecedentes." Existing local data is test-only (L2 Q3) but old states are still migrated with an explicit mapping.
- S6 — ANT-001 "Registrar finalidad, solicitante, persona, responsable y evidencia de autorización." `AutorizacionDatos`: "Finalidad, texto, versión, fecha, medio y revocación." ANT-002 "Generar una clave de idempotencia para evitar consultas duplicadas." "Solicitud duplicada: Devolver la operación existente; no repetir la consulta."
- S7 — PDF (ANT-006/007/008/009/010): "Aceptar solo PDF válido, dentro del límite y analizado contra malware." "Extraer documento, nombres, certificado, resultado, emisión y vigencia." "Comparar la identidad esperada; cualquier diferencia exige revisión." "Conservar bytes originales, SHA-256, fuente, fecha y cadena de custodia." "Verificar firma electrónica o mecanismo oficial cuando exista." Certificate layout (sample image, L3): labels "Fecha de Emisión", "Número de Certificado", "Tipo de Documento", "No. de Identificación", "Apellidos y Nombres", "Registra Antecedentes" (SI/NO), footer "Válido hasta el <d> de <MES> del <aaaa>", "Documento firmado electrónicamente". "PDF ilegible, cifrado o dañado: Mantener en cuarentena y solicitar otra carga o revisión." "Identidad no coincidente: Bloquear aceptación, preservar el original y escalar." Files are never served from public `/media/`.
- S8 — Roles (L2 Q4 answer to roles: "Rol dedicado + 4 ojos"): only role "Revisor de antecedentes" sees results/PDFs and validates; whoever uploaded cannot validate the same case; garita and others never see antecedentes. ANT-011 "Auditar toda lectura y ocultar el detalle a roles no autorizados." ANT-013 "Permitir revisión humana con decisión, motivo y segundo aprobador configurable."
- S9 — ANT-012 "Programar renovación o nueva consulta según vigencia y política." ANT-014 "Separar resultado, autenticidad documental y habilitación." Habilitación (`apps.accesos.services.calcular_habilitacion`) keeps reading only a VALIDADA, in-force verification with result NO.
- S10 — Tests in `apps/antecedentes/tests.py` for every rule; API per requirements: `/api/v1/verificaciones-antecedentes`, `/{id}`, `/{id}/continuar`, `/{id}/documento`, `/{id}/revision`, error code `ANT_CAPTCHA_REQUIRED`.
